# Phase 1 — Stabilization Implementation Record

**Date:** 2026-09-19
**Repo:** `D:\CyberAgent`
**Baseline:** `docs/SIH_ARCHITECTURE_AUDIT.md` (Phase 0, commit `f874173`)

## Goal

Stabilize the CyberAgent foundation so the baseline becomes dependable and
testable: explicit dependency management, migration-managed schema, safe startup,
valid CORS, a cleaned scan lifecycle, a dead-file-free frontend, and a pytest
suite that never touches the development database.

## Scope guarding

**Explicitly NOT implemented in this phase** (deferred to later phases per plan):
World Monitor integration; real auth/RBAC; real scanners; LLM/RAG/ML; real
report generation; Docker/Compose; CI. No new schema tables/columns; no new
dependencies beyond test tooling (pytest, httpx, alembic); no fake features.

## Completed work

### 1. Configuration bundle
- New `backend/app/config.py`: pydantic-backed `Settings` + module `settings`
  with `DATABASE_URL` (default `sqlite:///./cyberagent.db`), `SIMULATION_MODE`
  (default `true`), `CORS_ORIGINS` (comma-separated list), `REDIS_URL`
  (reserved). `load_dotenv()` lives here only.

### 2. Dependency manifests & env templates
- `backend/requirements.txt` (pinned run deps):
  `fastapi==0.141.1`, `uvicorn==0.53.0`, `SQLAlchemy==2.0.54`,
  `pydantic==2.13.5`, `python-dotenv==1.2.3`, `alembic==1.20.0`.
- `backend/requirements-dev.txt`: `pytest==9.1.1`, `httpx==0.28.1`.
- `backend/.env.example` and `frontend/.env.example` (names only — no secrets).
- Root `.gitignore` now un-ignores `*.env.example` and ignores `.pytest_cache/`.

### 3. Alembic migrations
- `alembic init alembic` under `backend/`; `alembic/env.py` imports
  `database.models.Base.metadata` as `target_metadata` and takes the URL from
  `app.config.settings` (ini `sqlalchemy.url` intentionally blank).
- Initial migration `d1c4eef2b66c` ("initial schema") autogenerated from the 8
  models; verified byte-identical (tables/columns/PKs/FKs) to the pre-existing
  `create_all` schema, plus `alembic_version`.
- Existing dev DB `backend/cyberagent.db` stamped to head (non-destructive).

### 4. Migration-aware startup
- `backend/database/connection.py` rewritten:
  - Engine/session from `settings.database_url`.
  - `verify_schema(engine)` — inspects, raises `RuntimeError` naming missing
    tables, never creates/drops anything.
  - `seed_defaults(db=None)` — idempotent demo user + "Default Sandbox"
    project + 6 seed assets; no DDL.
- `backend/app/main.py` rewritten:
  - Startup: `verify_schema()` → `seed_defaults()`.
  - CORS from `settings.cors_origins`, `allow_credentials=False`.
  - `/` reports `simulation_mode`.

### 5. Scan lifecycle
- `backend/app/agents/workflow.py`:
  - `[SIMULATION]` banner appended to `Scan.logs` when simulation is active.
  - `completed_at` set on **Completed** and **Failed** paths.
  - `save_tool_result(..., simulated=...)` prefixes stored tool output with
    `[SIMULATED]`; non-simulated output stored verbatim.
- `backend/app/api/scans.py`:
  - Trigger reads `settings.simulation_mode` (no hardcoded True), response
    includes `simulation`.
